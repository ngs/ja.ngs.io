2009 年 12 月に App Store でリリースした宿検索アプリ **宿さがし** を、SwiftUI でゼロから作り直して **v3.0.0** として公開しました。

じゃらん net と楽天トラベルをまとめて検索できます。

[App Store](https://apps.apple.com/jp/app/id347959354) / [公式サイト](https://yadosearch-app.ngs.io/ja/)

<!--more-->

## 16 年ぶりの後継

初代の宿さがしは 2009 年 12 月リリース ([当時の紹介記事](/2009/12/31/yadosearch/)) で、最終更新の v2.0.4 で止まっていました。

2014 年に UIKit で v3 を書きかけたまま放置していたため、今回はその書きかけを捨て、リリース版の機能を引き継ぐ形で SwiftUI で書き直しました。

Bundle ID が当時の `org.ngsdev.iphone.Yado` のままなため、ストア上は同じアプリへのアップデートで、16 年前に入れた端末にもそのまま v3.0.0 が届きます。

## できること

検索の軸は 4 つです。

- **キーワード検索** — 宿名の一部で探す
- **現在地検索** — まわり約 1km〜約 10km の宿を探す
- **地域検索** — 広域 → 都道府県 → 大エリア → 小エリアのドリルダウン
- **駅検索** — MapKit で駅を調べ、そのまわりの宿を探す

検索対象はじゃらん net・楽天トラベル・その両方から選べます。

初代はじゃらんのみ、v2 からは楽天トラベルを切り替え式で足していましたが、今回は検索結果で同じ宿を名寄せして並べ、予約先は宿詳細のセグメントで選ぶ形にしました。

並び順・宿の種類・予算・人数構成・設備・食事・部屋タイプなど約 70 条件で絞り込めます (絞り込みの多くはじゃらんにしか渡らない仕様で、一覧にその旨を表示します)。

このほかにできること:

- **宿詳細** — 写真・地図・宿泊プランと料金、予約ページへのリンク
- **宿泊プラン検索** — 日付・泊数・人数・部屋数を指定して空室と料金を見る
- **お気に入り / 閲覧履歴 / 検索条件の履歴** — SwiftData に保存、iCloud で端末間同期、検索条件は 1 タップで再実行

対応プラットフォームは iOS / iPadOS 26.0+ と macOS 26.0+ です。

## 技術的なこと

アプリはじゃらん・楽天の API を直接叩かず、自前のプロキシ [yadosearch-api](https://github.com/ngs/yadosearch-api) を経由するため、アプリ側に API キーが入っていません。

じゃらんと楽天でエリアコードの粒度も絞り込みの語彙も違うため、その差の吸収はプロキシとアプリで分担しています。

片方のサービスが失敗しても (楽天の 429 は普通に踏みます) エラーにせず、取れた結果を出して下に注記します。
