2009年12月に App Store でリリースした宿検索アプリ **宿さがし** を、SwiftUI でゼロから作り直して **v3.0.0** として公開しました。じゃらん net と楽天トラベルをまとめて検索できます。

無料で、広告もアプリ内課金もありません。

[App Store](https://apps.apple.com/jp/app/id347959354) / [公式サイト](https://yadosearch-app.ngs.io/ja/)

<!--more-->

## 16年ぶりの後継

初代の宿さがしは 2009年12月リリース（[当時の紹介記事](/2009/12/31/yadosearch/)）、最終更新は v2.0.4 で止まっていました。2014 年に UIKit で v3 を書きかけたものの、そのまま放置。今回はその書きかけを捨てて、リリース版の機能を引き継ぐ形で SwiftUI で書き直しました。

Bundle ID は当時の `org.ngsdev.iphone.Yado` のままなので、ストア上は同じアプリ（[ID 347959354](https://apps.apple.com/jp/app/id347959354)）へのアップデートです。16年前に入れてくれた方の端末にも、そのまま v3.0.0 が届きます。

## できること

検索の軸は4つです。

- **キーワード検索** — 宿名の一部で探す
- **現在地検索** — まわり約1km〜約10kmの宿を探す
- **地域検索** — 広域 → 都道府県 → 大エリア → 小エリアのドリルダウン
- **駅検索** — MapKit で駅を調べ、そのまわりの宿を探す

検索対象はじゃらん net・楽天トラベル・その両方から選べます。並び順や宿の種類、予算、人数構成、設備・食事・部屋タイプなど約70条件で絞り込めます（絞り込みの多くはじゃらん側だけに渡る仕様で、一覧にその旨を表示します）。

宿詳細では写真・地図・宿泊プランと料金を見て、そのまま予約ページを開けます。日付・泊数・人数・部屋数を指定した空室プランの検索もできます。

お気に入り・閲覧履歴・検索条件の履歴は SwiftData に保存し、iCloud（CloudKit プライベートデータベース）で端末間同期します。検索条件の履歴は1タップで再実行できます。

対応プラットフォームは iOS / iPadOS 26.0+ と macOS 26.0+ です。

## 仕組み

アプリはじゃらん・楽天の API を直接叩かず、自前のプロキシ [yadosearch-api](https://github.com/ngs/yadosearch-api) を経由します。API キーはすべてプロキシ側が持つので、アプリに資格情報が入っていません。

じゃらんと楽天はエリアコードの粒度も絞り込みの語彙も違うので、その差の吸収もプロキシとアプリで分担しています。片方のサービスが失敗しても（楽天の 429 は普通に踏みます）エラーにせず、取れた結果を出して下に注記します。
